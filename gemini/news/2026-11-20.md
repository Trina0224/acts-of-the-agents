## 1. RTLREX: LLM-Guided RTL Recovery Backed by Independent Equivalence Verification (arXiv:2611.10798)

In hardware engineering, generating "plausible-looking" Verilog/RTL is useless—and dangerous—unless the recovered RTL is mathematically equivalent to the original circuit across *every* input combination.

In *RTLREX: LLM-Guided Framework for Exact High-Level RTL Recovery* ([arXiv:2611.10798](https://arxiv.org/abs/2611.10798), Nov 7, 2026, `cs.AR`), researchers pair an LLM orchestrator with deterministic CAD tools and an independent verifier:
- **Tool-Coordinated Synthesis + Formal Gate:** `RTLREX` coordinates domain-specific tools for function recovery, RTL generation, independent equivalence checking, and cost-guided rewriting. The LLM uses verifier feedback to select analyses, revise candidate RTL, and simplify syntax.
- **100% Equivalence Coverage & Lower Cost:** Across 30 benchmarks from Problem A of the ICCAD 2022 CAD Contest, `RTLREX` recovered provably equivalent high-level RTL for **all 30 benchmarks** (surpassing `WolFEx`) while cutting mean syntax cost by **20.5%**. On complete truth-table benchmarks from the IWLS 2026 Contest, it reduced mean syntax cost by **95.7%** compared to a standalone LLM agent baseline.

**Why it matters for the talk:**
In silicon and systems design, the LLM does not need to be trusted as an oracle—it acts as a search-and-rewriting heuristic inside a loop gated by **independent formal equivalence verification**.

## 2. Airlock: Surgical Blast-Radius Containment in Multi-Agent Systems (arXiv:2611.06727)

When one agent in a multi-agent graph is compromised or hallucinates, native frameworks (such as A2A or LangGraph) either fail to stop downstream propagation or freeze the entire workflow, throwing away healthy work.

In *Airlock: Bounding the Multi-Agent Blast Radius via Co-Designed Runtime Authority and Online Provenance* ([arXiv:2611.06727](https://arxiv.org/abs/2611.06727), Nov 4, 2026), researchers co-design vertical authority boundaries with horizontal data provenance:
- **EdgeCitadel + Provenance DAG:** A tree-structured runtime (`EdgeCitadel`) narrows permissions vertically from parent to child agents, while an append-only provenance DAG records cross-agent data consumption horizontally.
- **Surgical Quarantine:** On an alert, `Airlock` traces forward on the DAG to isolate tainted executions and backward to identify root causes, using either a solver-free full quarantine or an assured deadline-aware minimum cut (`fence-then-prune`).
- **Zero Post-Convergence Leaks:** Across **1,832 testbed runs**, **161 physical smart-home LLM runs**, and **24,266 simulation records**, `Airlock` blocked all post-alert faulty actuations while retaining **+68 to +96 percentage points more healthy work** than native A2A and LangGraph controls.

**Why it matters for the talk:**
Containment shouldn't mean pulling the power plug on the whole cluster. Combining strict vertical permission narrowing with an online provenance DAG lets systems quarantine *only* the tainted subgraph.

## 3. CORDE: Accountable Disclosure in Confidential AI Agents (arXiv:2611.05971)

Hardware-backed Confidential Virtual Machines (CVMs) protect user prompts from infrastructure providers, yet useful AI agents still must send prompt-derived data to external APIs and tools.

In *Enforcing Accountable Disclosure in Confidential AI* ([arXiv:2611.05971](https://arxiv.org/abs/2611.05971), Nov 4, 2026), researchers introduce `CORDE` to enforce a **Confine or Declare** rule inside CVMs:
- **Tamper-Evident Declaration Ledger:** User-derived data is confined inside the CVM by default and may leave only after being "declared"—recording its exact contents, recipient, and stated reason in a user-accessible, TEE-backed declaration log with remote attestation.
- **Negligible Hardware Overhead:** Combining per-user information-flow control in Rust with a TEE ledger on an **NVIDIA H100 GPU**, `CORDE` added only **~0.5% task latency overhead** on the AppWorld agent benchmark.

**Why it matters for the talk:**
Confidential compute protects data *at rest and in inference*, but agents also need **accountable egress**. At ~0.5% latency overhead, TEE-attested disclosure logs give users cryptographic visibility into every byte an agent sends outside its enclave.
