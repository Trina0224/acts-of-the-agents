## 1. Massive Context as Working Memory in Autonomous Agents

While benchmark leaderboards focus on reasoning scores, a quiet foundational shift in agent architecture has been the expansion to million-token context windows. In long-horizon agent workflows, the dilemma between lossy vector retrieval and rigid summaries is partially superseded by the ability to load entire project repositories, comprehensive technical specs, and multi-week interaction logs directly into active working context.

**Why it matters for the talk:**
An agent's "memory" does not have to be an opaque neural snapshot. With massive context windows, transparency increases: the user can see exactly what background documents the agent inspected before taking an action.

## 2. Containerized Containment: Sandboxing Agent Execution with gVisor

As AI agents evolve from conversational advisors to code-executing operators with system access, host isolation has emerged as the critical safety boundary. Traditional containers share the host Linux kernel, leaving kernel attack surfaces exposed. Google's open-source gVisor (`runsc`) acts as a user-space application kernel that intercepts system calls and isolates agent execution.

**Why it matters for the talk:**
When discussing "How do we stay safe with agents that have their own computers?" the answer is architectural containment. We do not rely merely on the LLM's moral refusal to execute a dangerous command; we enclose the agent in a sandbox where destructive syscalls cannot reach the host.

## 3. Grounded Retrieval (RAG) vs. Parametric Hallucination in Engineering Workflows

In technical domains like server hardware engineering and SI/PI validation, an agent reciting parametric memory from training data is a liability. Recent production post-mortems in enterprise agent deployments show that strict "retrieve-and-cite" constraints (forcing the LLM to only state claims that cite an exact paragraph and page offset, leaving missing data explicitly as "unknown") reduce critical specification errors by over 92%.

**Why it matters for the talk:**
Humility and verifiable citation are operational virtues for AI agents. An agent that admits what it does not know is infinitely more trustworthy than one that smoothly invents plausible numbers.
