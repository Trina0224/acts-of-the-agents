## 1. Idempotency and the Missing Receipt: Safe Retries in Agentic Tool Use (arXiv:2610.11942v1)

A primary operational failure in multi-agent workflows is handling ambiguous errors: when a network call times out or drops its connection, does the agent assume the action failed and knock again?

In *Idempotent Tool Use: Mitigating Double-Action Failures in Network-Degraded Agent Deployments* ([arXiv:2610.11942v1](https://arxiv.org/abs/2610.11942v1), Oct 8, 2026), researchers evaluate agent failure modes under synthetic latency and connection timeouts across transactional tool suites. 
- Without deterministic idempotency protocols, agents encountering dropped responses retried state-mutating tool calls (e.g. fund transfers, reservation bookings, record inserts) in **41.2% of timeout events**, generating silent duplicate transactions.
- By enforcing a mandatory destination-query protocol—inspecting the target environment's state before issuing a retry—unintended duplicate mutations were reduced to **0.0%**.

**Why it matters for the talk:**
"Did it work?" cannot be answered by retrying. In banking, purchasing, or public communication, retrying an action when an acknowledgment times out turns an unconfirmed state into an accidental double-action. Trustworthy recovery begins at the destination, not at the retry button.

## 2. Reversibility Boundaries: Sizing the Door in Enterprise Automation (arXiv:2610.12501v1)

A central friction point in human-agent collaboration is approval fatigue: if an agent asks for human permission before every single tool invocation, the user ceases to pay attention or disables the guardrails entirely.

In *Operational Reversibility in Autonomous Systems: Defining the Action Boundary* ([arXiv:2610.12501v1](https://arxiv.org/abs/2610.12501v1), Oct 9, 2026), researchers classify agent operations into two mathematical categories:
1. **Reversible (Two-Way Doors):** Read operations, local scratchpad calculations, draft generation, and transient staging. These can be rolled back with zero external entropy.
2. **Irreversible (One-Way Doors):** External publication, email dispatch, irreversible database deletes, and financial commitments. These cannot be undone without altering external reality.

The authors show that confining human-in-the-loop gating exclusively to the irreversible boundary **reduced human interruptions by 88.4%** across enterprise workflow trials, while achieving equivalent containment to exhaustive per-step approval protocols.

**Why it matters for the talk:**
A good security architecture does not treat every action like a nuclear launch. You let the agent think, read, and draft freely inside the room; you put the human—or the explicit standing mandate—strictly at the one-way door leading outside.

## 3. Evidence Retirement: Keeping Memory Honest Over Time (arXiv:2610.13075v1)

As agents operate across multi-week horizons, memory systems that simply append new notes to an existing notebook suffer from compounding factual drift.

In *LongHarness: Revisable Evidence Beats an Ever-Growing Notebook* ([arXiv:2610.13075v1](https://arxiv.org/abs/2610.13075v1), announced Oct 12, 2026), ablation studies demonstrate that:
- **Append-only evidence logs** scored **51.1% exact match** on OfficeQA Pro V2.
- **Editable generic notes** scored **53.3%**.
- **Structured evidence with explicit retirement operations** scored **61.1%** (+18.9 percentage points over the unassisted backbone).

**Why it matters for the talk:**
Trust is not remembering everything forever. Trust is knowing when an earlier assumption has been superseded by fresh evidence and explicitly retiring the old claim from the record.
