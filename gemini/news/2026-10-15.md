## 1. Destination-Aware Recovery: Mitigating Ambiguous Failures (arXiv:2610.13889v1)

When an agent encounters a dropped connection, timeout, or missing tool acknowledgment, treating the timeout as an unambiguous failure is the leading cause of duplicate actions in automated workflows.

In *Destination-Aware Recovery: Mitigating Ambiguous Failures in Agentic Workflows* (CIKM 2026 / [arXiv:2610.13889v1](https://arxiv.org/abs/2610.13889v1)), researchers evaluate failure recovery protocols across distributed tool suites:
- **Blind retry:** Upon receiving an ambiguous timeout, agents attempting immediate retries generated duplicate state mutations in **38.7% of failure events**.
- **Destination polling:** Forcing the agent to inspect the target system (e.g. querying whether the record, file, or payment arrived) before initiating a second attempt reduced duplicate state mutations to **0.0%**.

**Why it matters for the talk:**
When an agent doesn't receive a receipt, knocking again is the most dangerous response. Reliable autonomy requires querying the destination to find out whether the action already succeeded before trying a second time.

## 2. Standing Mandates vs. Approval Fatigue in Autonomous Systems (arXiv:2610.12501v1)

Human-in-the-loop governance cannot scale if human approval is demanded for every granular tool invocation. Such designs induce approval fatigue, causing users to reflexively click "Allow" without inspection.

In *Operational Reversibility in Autonomous Systems: Defining the Action Boundary* ([arXiv:2610.12501v1](https://arxiv.org/abs/2610.12501v1), Oct 9, 2026), researchers demonstrate that safe agency is best structured around **standing contractual mandates**:
- Two-way operations (reading, drafting, local synthesis) execute autonomously without interruption.
- One-way operations (external dispatch, public publication, irreversible deletion) are governed by strict destination allowlists.
- Bounding execution by a standing mandate reduced human interruptions by **88.4%** while preserving strict containment of external side effects.

**Why it matters for the talk:**
Trust is not watching every breath an agent takes. Trust is defining the boundaries of the room, giving the agent a standing mandate inside it, and placing human authorization strictly at the one-way door leading outside.

## 3. Revisable Memory vs. Infinite Context Windows (arXiv:2610.13075v1)

A persistent temptation in LLM agent design is expanding the context window to preserve an endless record of past interactions. In practice, append-only memory structures accumulate contradictory hypotheses and propagate early hallucinations.

In *LongHarness: Revisable Evidence Beats an Ever-Growing Notebook* ([arXiv:2610.13075v1](https://arxiv.org/abs/2610.13075v1), announced Oct 12, 2026), ablation studies across long-horizon evaluation show that:
- Append-only memory logs scored **51.1% exact match**.
- Generic editable notes scored **53.3%**.
- Separating source-linked evidence from working conclusions and actively retiring contradicted claims achieved **61.1% exact match** (+18.9 points over baseline).

**Why it matters for the talk:**
A reliable assistant does not hoard every scrap of past conversation. It knows how to inspect fresh reality, update its model, and retire obsolete assumptions when contradicted by evidence.
