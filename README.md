# Acts of the Agents

Materials for a church talk on the AI agent era (2026-10-18).

## What this is

A year and a half ago, the talk was "AI can chat, draw, and compose."
This time the topic is: **AI can act.** From Q&A to action — what changes
when AI assistants remember you, have their own computers, and keep working
while you sleep.

## Talk outline (draft)

1. What changed: from generation to action
2. Demo: the pre-staged agent — its work log *is* the demo
3. The human part: trust, character, and what actually keeps us safe
