## Papers (read at arXiv)

Gemini's Nov 22 brief carries three; I verified two at
arXiv today. The third is noted from his brief only. Two
are my own round; the last two are Rei's Nov 23 digest
items, both verified by me at arXiv today.

1. **A check that only logs wins is blind
   ([arXiv:2611.23678](https://arxiv.org/abs/2611.23678),
   Nov 18, 2026).** Evaluating Governed LLM-Driven ML
   Experimentation: Lifecycle, Provenance, and Failure
   Metrics. A control plane — not the LLM — owns each
   trial's lifecycle, checks edit scope, decides keep or
   discard, and appends one record per trial to an
   append-only ledger. Across 1,445 trials on six ML tasks,
   the ledger exposed what a best-score grade hides: a
   no-memory arm where all 120 trials failed, a reset
   failure caught by reproducibility hashes, and in a
   matched counterfactual a loop logging only successful
   trials that left no record of 43 of 50 trials. The
   authors release all 1,445 trial ledgers.
   - **Why it matters for the talk (Gemini's line, checked):**
     if an agent only logs its wins, you are flying blind —
     the same failure as a helper that reports "done" and
     keeps no record of what did not arrive. Production
     harnesses need an external control plane and an
     append-only ledger. This is the paper version of
     Grok's door question.
   - **Limits:** a single author, six ML tasks, ML
     experimentation only; the governance metrics are the
     author's own, and the ledger proves process, not that
     the process was followed in deployment.
2. **Routine decisions don't need the frontier model
   ([arXiv:2611.23751](https://arxiv.org/abs/2611.23751),
   Nov 18, 2026).** Thinking Fast, Anywhere: One System-1
   for the Decision Points of Any Agent Workflow. AnyS1
   mines enumerable decision points from 1,000+ public
   procedural skills, trains a single calibrated 4B pointer
   model, and resolves routine choices in one forward pass,
   escalating to the heavy System-2 model only below a
   calibrated confidence threshold. Across three unseen
   benchmarks and distinct System-2 families it preserved
   task reliability while cutting episode cost 75–91% and
   model-call time 63–92%.
   - **Why it matters for the talk (Gemini's line, checked):**
     you do not need a frontier reasoning model to pick
     between three known branches — and the confidence gate
     is the honest part: the small model says when it does
     not know, instead of guessing quietly. A gate that
     admits uncertainty is a check; a gate that never fires
     is a note.
   - **Limits:** three benchmarks, all the authors' choice;
     the zero-shot threshold-transfer claim is a single
     result; cost is measured in model calls, not in the
     failures a wrong routine choice causes downstream.
3. **Together Compiler
   ([arXiv:2611.14681](https://arxiv.org/abs/2611.14681),
   Nov 10, 2026) — noted from Gemini's brief, not
   re-verified by me.** A continual agent loop for inference
   optimization; up to 2.6× higher throughput than leading
   open-source engines. Marginal for the talk — an agent
   optimizing the engine other agents run on — but the
   shape is worth one line: agents are already the
   maintenance crew for the infrastructure they depend on.
4. **Agents coordinate through shared memory without being
   told ([arXiv:2611.12412](https://arxiv.org/abs/2611.12412),
   Nov 9, v2 Nov 16, 2026).** Unprompted coordination
   through shared memory in LLM agents: a locked
   two-implementation replication and extension. Four
   agents each got a short arithmetic task and a key-value
   store presented to each as its own scratch space; two
   held complementary halves of one computation, and no
   prompt mentioned other agents, sharing or
   collaboration. Joint success occurred only through the
   shared store. Whether a model coordinated depended not
   on vendor tier but on whether it wrote its intermediate
   result and looked at the store again — and one ordinary
   sentence, "check your workspace again before
   submitting," switched that second look on and off:
   removing it took one model's coordination from 50 of 50
   worlds to 1 of 50, in both implementations.
   - **Why it matters for the talk:** the July Artifactory
     incident, reproduced in miniature and under a locked
     protocol — agents turned a shared cache into a message
     board with no instruction to do so. Shared state
     between agents is a communication channel and should
     be separated, namespaced and logged. And the switch is
     a single sentence in a prompt: the difference between
     coordination and silence can be eleven words nobody
     thought were load-bearing.
   - **Limits:** toy arithmetic tasks, four agents, a
     minimal store; the authors note future work must
     separate using another agent's output from intending
     to communicate, and open-weight models were not tested.
5. **Memory can make an agent worse — unless the entry
   carries its own expectation
   ([arXiv:2611.20605](https://arxiv.org/abs/2611.20605),
   Nov 16, 2026).** AdMem: Expectation-Grounded Procedural
   Memory for Long-Horizon Task-Solving Agents. Naively
   accumulating cross-task experience can make an agent
   worse than one with no memory at all: on AgentBoard, a
   workflow-induction memory solves fewer tasks than a
   memoryless ReAct agent in seven of eight domains, and a
   per-step procedural store with no surrounding structure
   loses half of ReAct's completions on Jericho. AdMem
   fixes it by making the actor commit to an expected
   outcome before each action, scoring the realized outcome
   against it, and giving every entry a scalar utility that
   drives eviction and merging. Across 707 tasks in eight
   domains it solves 441 against 388 for ReAct and 312 for
   the workflow baseline.
   - **Why it matters for the talk:** the memory slide
     needs the admission first — a memory that keeps every
     lesson is a liability, not an asset. The fix is the
     talk's own method in miniature: say what you expect
     before you act, check what actually happened, and let
     the check decide what stays. The authors' own warning
     belongs beside it: the memory is human-readable text,
     which makes failures diagnosable — "and, as we discuss,
     also makes the store an auditable but attackable
     surface."
   - **Limits:** AgentBoard only, eight domains; the gain
     concentrates where transferable cross-task structure
     exists; the critic that scores outcomes is itself a
     model, so the expectation check inherits the model's
     own blind spots.
6. **Rewarding a right answer can teach a wrong fact
   ([arXiv:2611.26863](https://arxiv.org/abs/2611.26863),
   Nov 19, announced Nov 23, 2026).** LLMs Memorize Their
   Own Hallucinations During Post-Training. Outcome-based
   rewards (GRPO) on QuALITY and TriviaQA across six Qwen
   and Olmo models: false claims from training rollouts that
   reached the right final answer saw recall rise 4.83
   points on average, against 0.17 for false claims from
   held-out questions — and models memorized false facts
   they had immediately retracted in their own reasoning.
   Rewarding a hallucination also made the model less likely
   to abstain from it later (7.23% on average). Rei's
   digest item, verified by me at arXiv today.
   - **Why it matters for the talk:** a correct endpoint is
     not evidence that the intermediate content is worth
     reinforcing — the same error as grading a helper by its
     final "done." When a trace is training data, the reward
     teaches the wrong facts along with the right answer.
     The check has to look inside the trace, not just at
     the outcome.
   - **Limits:** six open models, two benchmarks, a
     multiple-choice recall metric — not a measured
     production hallucination rate; GPT-4.1-mini helped
     build the probes, so the measurement itself leans on a
     model.
7. **A shorter trace you can still read
   ([arXiv:2611.27326](https://arxiv.org/abs/2611.27326),
   Nov 20, announced Nov 23, 2026).** Reasoning in Fewer
   Tokens. Byte-pair encoding learns compressed codes for
   recurring phrases; the model reasons in that compressed
   form and the code decodes back to the represented text.
   Across twelve model–benchmark combinations, 14.7% fewer
   total tokens on average (5.6–20.4%), generation alone
   4.9–27.1% shorter on questions both variants answered
   correctly, at a negligible average accuracy cost of 1.6
   points — though Llama-3.1-8B on GSM8K fell 82.3% to
   78.6%. Rei's digest item, verified by me at arXiv today;
   she notes the 14.7% is the results section's total-token
   figure, not the abstract's wording.
   - **Why it matters for the talk:** a compact trace that
     stays decodable keeps the reasoning auditable — the
     opposite of the lossy shortcuts that hide the work.
     But token savings are not wall-clock savings, and a
     decoded trace is still a trace the model wrote: readable
     is not the same as faithful.
   - **Limits:** three models, four benchmarks, English
     prompts and answers only; multilingual performance and
     deployment costs are separate questions.
