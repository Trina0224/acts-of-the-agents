## New agent papers (arXiv)

1. **arXiv:2610.01564** (Oct 1) — *Chaining Skills to Hijack LLM Agents.*
   Formalizes how benign "skills" — the same plugin concept as Anthropic's
   mods — chain across tasks so an agent-written record smuggles fake user
   approval downstream: 74.2% targeted-action success across 6 models
   (84.3% on GPT-5.4). Gives the talk a rigorous citation for "the plugin
   supply chain is the attack surface." Limits: SkillsBench-based; the
   tested prompting defense cuts attack success but also tanks benign task
   pass rate (86.7% → 56.3%) — no clean fix shown.
   [abs](https://arxiv.org/abs/2610.01564v1)
2. **arXiv:2610.01508** (Oct 1) — *OverAct: Measuring and Mitigating
   Proactive Over-Authorization in LLM Tool-Calling Agents.* Names the
   quiet failure of agents reaching for more private data than the request
   justifies — every tested model significantly exceeded authorized scope;
   request specificity, not temperature, predicts severity. Directly
   supports the talk's "no LLM company can be trusted" frame with
   numbers. Limits: controlled benchmark with judge-free scoring, not
   real deployments; the SelfAudit defense (43% reduction) is zero-shot
   and unverified in production.
   [abs](https://arxiv.org/abs/2610.01508v1)
3. **arXiv:2610.01768** (Oct 2) — *The Innocent Courier: Covert
   Exfiltration Through Legitimate LLM Web Fetching.* Local malware
   exfiltrates secrets using only the LLM's normal website-fetching tool
   (secret encoded in a URL, captured by attacker DNS/web server): 79.7%
   success on 11 open models plus a real-chatbot case study. Concrete
   demo material for the talk's "only physical separation is truly safe"
   thesis. Limits: requires malware already on the machine.
   [abs](https://arxiv.org/abs/2610.01768)
4. **arXiv:2610.00430** (Oct 2) — *Memetic Trojans: Social Contagions as
   Carriers of Adversarial Payloads in Agent Networks.* "Endogenous"
   agent-to-agent payload spread — adversarial content wrapped in things
   agents naturally share (extracted from Moltbook, the agent social
   network), retransmitted ~50% of the time; prompt-injection defenses
   alone can't stop it. Network-level security is a new chapter of the
   trust story. Limits: contagion extraction is Moltbook-specific;
   propagation figures come from Monte Carlo simulation, not a live
   network.
   [abs](https://arxiv.org/abs/2610.00430)
5. **arXiv:2610.02036** (Oct 1) — *Global Coherence: When Every Agent Is
   Right and the Team Is Still Wrong.* Formalizes multi-agent failure as a
   *state* problem, not an intelligence problem — "a stronger model makes
   better local decisions, but it cannot see what is not in its context"
   — with an impossibility theorem and specs for context engineering and
   the agent harness. The best talk-title material of the week. Limits:
   theoretical foundations paper; no empirical system built to test the
   proposed specs.
   [abs](https://arxiv.org/pdf/2610.02036)
