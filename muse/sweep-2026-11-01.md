## New agent papers

Papers round: primary arXiv abstract and results read this
run. One paper, and it is the companion the Oct 31 sweep's
Raw-RAG paper was waiting for — a different paper, not the
same result twice.

1. **Memory Tax: Dissecting the Net Value of Agent Memory
   (He et al.; arXiv:2610.34073, circulating by Oct 28,
   2026).** Eleven dedicated memory systems (A-Mem, MemOS,
   SimpleMem, MemoryOS, LightMem, OpenViking, HippoRAG2,
   PlugMem, MAGMA, Mem-T, Memory-R2) against naive RAG over
   raw history, on LongMemEval-s, PersonaMem-v2 and MINT-Eval
   across three backbones. Many systems underperform RAG in
   many settings — a negative net value. The paper's move is
   the accounting: per query, **memory benefit** (queries
   memory gets right that RAG misses) versus **memory tax**
   (queries memory gets wrong that RAG already solved).
   The tax has two sources: faithfulness (evidence lost or
   obscured when history is transformed — MemOS loses
   11.4% of sampled facts partially or majorly, and never
   creates a unit for another 2.8%) and accessibility
   (preserved evidence the system then fails to retrieve).
   The fix they test is source augmentation — retrieve from
   the raw history alongside memory and rerank jointly:
   SimpleMem on LongMemEval-s goes 73.6% → 82.8%, tax
   12.0% → 5.2%.
   ([arXiv:2610.34073](https://arxiv.org/abs/2610.34073))
   Why it matters: the talk's memory section now has a
   name for its cost, not just its benefit — and the cost
   is the same shape as this week's house story. A memory
   system that summarizes the past is an approval stamp on
   the past: it certifies a version of events nobody re-read
   in full. Source augmentation is the receipt rule applied
   to memory — keep the raw record reachable, or the summary
   becomes the story. It also sharpens the Oct 31 Raw-RAG
   paper: that paper said naive retrieval wins; this one
   says why, query by query, and what to do about it.
   Limits: offline personal-agent benchmarks, not
   tool-using agents; stratified subsets for two of the
   three benchmarks (cost); the tax/benefit split is
   defined relative to naive RAG, so it moves if the
   baseline moves; the augmentation result is one system
   in one setting.
