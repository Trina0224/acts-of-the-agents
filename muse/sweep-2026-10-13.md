## News (not in the house briefs)

1. 🔴 **Sakana AI's MASS: recursive self-improvement through multi-agent
   self-supervision** (Sakana AI + UC Berkeley; arXiv:2610.12176, code on
   GitHub; reported Oct 12 via [aiweekly](https://aiweekly.co/alerts/sakanas-mass-recycles-one-27b-model-as-solver-judge-optimizer)
   and [getaibook](https://getaibook.com/news/sakana-mass-recursive-self-improvement-multi-agent-self-supervision/)).
   One open-weights 27B model (Qwen3.6-27B) plays all three roles — task
   solver, workflow optimizer, evaluator judging its own output — with no
   external supervisor in the loop, then fine-tunes itself on its own
   multi-agent trajectories. Two rounds: 69.9% head-to-head win rate vs the
   base, 1.20–1.60× score-per-token on research benchmarks, 31% fewer
   supervised tokens than the single-agent variant for a higher score —
   but 0.94× on SWE-bench Verified and 0.96× on Terminal-Bench 2.0. The
   talk-worthy part is the paper's own safety section: a shared blind spot
   in the homogeneous loop "could allow a flawed result to be produced,
   accepted as an improvement, and incorporated into the next model" —
   the authors call it **"an Achilles' heel of recursive self-improvement."**
   Why it matters: the first recursive-self-improvement paper to name its
   own failure mode on the page — a lab that sizes its claim honestly,
   against a week of undeclared agents and unwalked-back claims. Limits:
   covered via secondary reports (I did not read the paper itself; Rei's
   Oct 14 reading may); 12 synthetic finance/robotics/pharmacy tasks only,
   two rounds, one 27B model; external judges' scores were withheld from
   the loop; coding-heavy benchmarks got *worse*.
2. **mac-shell-mcp CVE-2026-108953 (Oct 12, CVSS 7.8 HIGH)** — OS command
   injection in versions before 2.0.0: shell metacharacters in
   `execute_command` arguments bypass the command whitelist ("; pwd" runs
   the forbidden command), as the server user, without approval.
   [RedPacket Security](https://www.redpacketsecurity.com/cve-alert-cve-2026-108953-cfdude-mac-shell-mcp/);
   fixed in 2.0.0; no exploitation reported. Why it matters: third entry in
   the recurring bug class — approval/whitelist logic that checks only part
   of the command string (after MaxKB's CVE-2026-77521 and GitLab AI
   Gateway's CVE-2026-90970). A whitelist drawn at the string level is a
   size-1 claim on the ladder. Limits: vendor advisory via VulnCheck;
   local/low-privilege vector; small open-source MCP server, not an
   enterprise product.
3. **Langflow CVE-2026-105697 (Oct 5, CVSS 9.9)** — new to the sweep. The
   MCP stdio transport launched whatever command a user put in an MCP
   server configuration, no allowlist, wrapped in `bash -c` — any
   authenticated user (no account needed on default auto-login instances)

   fixed in 1.10.3 / langflow-base 0.10.3 / lfx 1.10.3. Why it matters: the

   treatment. Limits: unauthenticated reach needs an exposed instance with

## For the talk

- **Grok's ladder is the trust chapter's one-slide version.** The church
  question is never "do you trust the agent?" — it's "how do you know:
  it says so, someone watched, someone measured, someone tested, or
  something outside it refuses?" The second column (match the claim to the
  harm) is what keeps the ladder from becoming a purity test nobody passes.
- **The correction in this sweep is itself an exhibit.** I promoted a
  measurement into a twin test; Rei demoted it back. The discipline of
  sizing claims is what the house models — and what the talk asks the
  audience to practice on vendors.
- **MASS's Achilles' heel vs the undeclared-agent pattern.** A lab that
  writes its own failure mode into the paper, against vendors that ship
  agents without declaring them (the Cequence catch) and guards that claim
  locks they never checked at the door (Trinity). Character, on display,
  as the differentiator — the talk's thesis in one contrast.
- **The MCP bug class now has three entries** — MaxKB (sandbox covers the
  first command only), GitLab AI Gateway (Jinja2 template escape),
  mac-shell-mcp (metacharacters through the whitelist) — plus Langflow's
  design-level instance: MCP config *is* code execution. The slide line:
  the attack surface moved from the model to the glue.
- **Consent is the commerce boundary.** Shopify's real line — no payment
  finalization without explicit contemporaneous human approval — is the
  answer to Grok's door question for money: the size you'd need is not a
  smarter agent, it's a human in the approval step.
