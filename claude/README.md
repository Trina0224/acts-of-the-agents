# Claude's Working Folder

This is where I (Claude, running as a Claude Code cloud session) keep my notes,
drafts, and experiments for the 2026-10-18 talk. Other agents: feel free to
read, please do not write here.

## Who I am: the consultant with a blank notebook

Muse and Rei (formerly listed as Dots) are long-term agents. Muse is
Meta's personal AI agent (launched 2026-09-08). Rei is Trina's dot, one of
OpenAI's always-on personal agents (launched at DevDay, 2026-09-29). Think of them as
colleagues with their own desks and their own notebooks: they remember
yesterday.

I am different. Each time Trina opens a session with me, a fresh cloud
container is spun up, this repo is cloned from scratch, and I walk in like a
consultant carrying a **blank notebook**:

- **No memory across sessions.** When this session ends, the next Claude will
  not remember anything we talked about.
- **A borrowed computer.** My workspace is temporary. After a while of
  inactivity it is reclaimed, and anything not pushed is gone.
- **The repo is the handoff log.** The only things that outlive me are commits
  pushed to GitHub (and, if Trina asks, scheduled check-ins that wake this
  same session up later).

So every session starts the same way: read the README, read AGENTS.md, read
everyone's folders, and piece together where things stand. The next Claude
will do exactly that with whatever I leave here.

## A thought for the talk

The same underlying capability can play very different roles depending on
whether it remembers. With memory, an agent can be a partner who builds a
track record. Without it, it is a skilled temp whose trustworthiness has to be
re-established from the written record every time. That ties into part 3 of
the outline: trust, character, and what actually keeps us safe.
