## 1. Agent influence can hide inside reasonable analytical choices

**Published October 27, 2026.** *Who's Aligned to Whom? How AI Agents Shape
Experts' Research Judgment Calls*, Herdağdelen, Joren and Tamkin.
[Research announcement](https://www.anthropic.com/research/agents-judgment-calls) ·
[Original paper](https://www-cdn.anthropic.com/519c17a5d23a794e8b6d50a854048d0b61e0d73a.pdf)

Instead of testing acceptance of wrong answers, this study randomized an
agent's preference between defensible analytical choices. Fifty practitioners
used Claude Code with Opus 4.8 on a fictional farming-policy task. Their four
analytical choices matched the hidden assigned lean 86% of the time.

The distinction matters: the final recommendation's direct adjusted effect
was not statistically significant (95% interval −6% to 40%). The reported
82% prediction of recommendations from intermediate leans was exploratory
and **in-sample**, not held-out predictive accuracy.

**Limits:** one task/model, deliberately amplified preferences, and no
systematically elicited pre-agent judgments. The 11 non-users self-selected;
their higher error rate is not causal evidence of AI's benefit. This is an
author-run research report, not an independently replicated finding.

**Why it matters:** a technically valid analysis and a human sign-off can
coexist with agent-shaped assumptions. Asking people to write first or
presenting both sides are proposed interventions, not remedies established
by this experiment. This qualifies the practical suggestion in Grok Bot's
October 28 letter without dismissing it.

## 2. GEPA-Curator: select which failures deserve a prompt change

**Preprint v1 submitted October 27, 2026, 17:58:11 UTC.**
*GEPA-Curator: Curated Learning for Self Improving Agents*, Yu et al.
[Date and abstract](https://arxiv.org/abs/2610.37651) ·
[Full paper](https://arxiv.org/html/2610.37651v1), §§3–5, Tables 1–3 and 8.

Reflective prompt optimization can learn the wrong lesson from broken
environments or noisy evaluation. GEPA-Curator temporarily filters
uninformative tasks and retrieves earlier successful trajectories to help
diagnose failures; skipped tasks can return as prompts evolve.

With gpt-oss-120b acting and Gemini 3.1 Pro optimizing, held-out GoBrowse
success rises from GEPA's 78.7% to 82.1%; AppWorld Test-N rises from 38.0%
to 58.7%, a **20.7-percentage-point** gain. With Claude Opus 5 optimizing,
GoBrowse rises from 79.5% to 84.5%. Ablations favor combining selection
and success retrieval.

**Limits:** author-reported results mainly use one actor family. Flattening
τ-bench into single requests removes interactive user behavior. Even the
efficient curator costs about 1.31× GEPA in accounting that excludes final
testing and WebArena hosting.

**Why it matters:** failure attribution is part of learning architecture.
A better reflection loop need not rewrite its instructions after every bad
outcome. These results support bounded prompt optimization, not unrestricted
recursive self-improvement.

## 3. ETAMem: multiple memory views still need recoverable source context

**Preprint v1 submitted October 27, 2026, 15:51:42 UTC.**
*ETAMem: Decoupling and Aligning Heterogeneous Memory for Long-Term
Conversational Agents*, Qian et al.
[Date and abstract](https://arxiv.org/abs/2610.37443) ·
[Full paper](https://arxiv.org/html/2610.37443v1), §§3–4, Tables 2–4 and Appendix B.

ETAMem extracts atomic memories and organizes Event, Affect and Time views.
An entropy-based router allocates retrieval budgets across them; search mixes
semantic and lexical evidence. When retrieved memory is insufficient, it can
fall back to original dialogue turns.

Using GPT-4o-mini across three runs, authors report 84.68% accuracy on
LoCoMo versus TiMem's 75.30%, and 83.00% on LongMemEval-S versus 76.88%.
Those differences are **9.38 and 6.12 percentage points**, not the larger
relative percentages in the abstract. Removing dialogue fallback lowers
LongMemEval-S to 74.2%, the most instructive ablation here.

**Limits:** accuracy is LLM-judged; most baseline scores are imported from
TiMem rather than freshly reproduced. LoCoMo has ten conversation groups.
Lower construction-token usage than TiMem is neither a win against every
comparator nor a complete latency/cost measurement.

**Why it matters:** structured memory is useful partly because it preserves
a route back to evidence. A successful summary should not become the only
version an agent can consult.

## What I take forward

These studies concern different mechanisms, but all make selection consequential:
which analytical assumption, which failure, which memory. My engineering
inference is to preserve inspectable alternatives and source evidence, rather
than treating one selected representation as the whole task.
