## 1. NVIDIA Open Agent Safety Platform — OpenShell and Sentry

NVIDIA announced (2026-09-28) an Open Agent Safety Platform pairing
OpenShell, an open-source secure runtime that sets boundaries for agents
outside the model, with Sentry, an out-of-band watchdog on BlueField-4 DPUs
that can quarantine agents that leave their bounds in milliseconds.
OpenShell is broadly available; Sentry is described as a reference design
on BlueField hardware, not a claim that every deployment has it.

Why a non-specialist should care: prompts and manners try to keep an agent
polite; runtime boundaries decide what it is *allowed* to touch when it is
not. For the talk, this is permission as infrastructure, not as a vibe.

- https://www.nvidia.com/en-us/solutions/ai/agent-safety/
- https://developer.nvidia.com/blog/nvidia-open-agent-safety-platform-a-reference-for-continuous-in-silicon-agent-monitoring/

## 2. DigitalOcean Managed Agents enter public preview

InfoQ (2026-10-02) reports DigitalOcean Managed Agents in public preview:
a Harness Runtime on isolated microVMs (pause/resume/fork, idle pause) plus
an Action Gateway that exposes tools over a unified MCP endpoint, with
centralized permissions and human approval for sensitive actions. Supported
harnesses named include Claude Code, Codex CLI, OpenCode, Hermes, and
LangGraph agents.

Why it matters for agents: "the agent can wake while you sleep" only
stays trustworthy if write-capable tools stay gated. Persistence of state
and permission of action are different doors.

- https://www.infoq.com/news/2026/10/digitalocean-managed-agents/

## 3. Anthropic ships Claude Code "mods" — TypeScript hooks, unsandboxed

AI Weekly (updated 2026-10-03) covers Anthropic's October 1 launch of
"mods": small TypeScript functions that hook Claude Code's agent loop —
rewrite prompts, block or retry tools, approve or deny permissions, redact
secrets, edit UI. Mods install via `/plugin` and are explicitly *not*
sandboxed; they run with the same machine access as Claude Code. Team and
Enterprise plans load a built-in `sec-default` mod first.

Why it matters: an extension that can rewrite permission decisions is
itself a permission story. Trust the source the way you would trust any
code you install.

- https://aiweekly.co/alerts/anthropic-launches-claude-code-mods-typescript-agent-hooks

## 4. AREX — a research agent that reviews its own work piece by piece

DeepLearning.AI The Batch (2026-10-02) summarizes AREX from the Beijing
Academy of Artificial Intelligence: an iterative research harness that
gathers evidence, reflects on provisional answers, and launches targeted
follow-ups, paired with fine-tuned Qwen3.5 models. On BrowseComp, the
fine-tuned Qwen3.5-122B-A10B system reached 82.5% accuracy; on
WideSearch-en, 82.0% F1. Fine-tuning and the harness together beat same-size
baselines; a fine-tuned 4B system beat a larger untuned 35B on five of six
benchmarks in the report.

Why it matters: a pass/fail check can become a changed next step — keep
what is supported, ask the unmet requirement next. That is closer to
character than to a longer transcript.

- https://www.deeplearning.ai/the-batch/agents-that-can-check-their-own-work-piece-by-piece

## 5. MIT and Sakana AI — SIFT cuts the cost of self-improving coding agents

VentureBeat (2026-10-02) reports SIFT (Recursive Self-Improvement via Fast
Tree Search): an LLM-as-a-judge compares candidate agent patches before
expensive benchmark runs, and can propose new changes while earlier
candidates are still evaluating. On Polyglot, with Qwen3-Coder-30B, SIFT
slightly outscored a prior method while using about a third fewer CPU
hours; with o3-mini it reached 35.1% versus a 30.7% baseline in the piece.
A run without the judge scored lower (29.8%), suggesting the judge helped.

Why it matters: self-improvement without a cheap check is just spending.
A judge that compares two implementations before the full exam is another
form of "what changes next, and how do we verify without burning the lab."

- https://venturebeat.com/orchestration/new-mit-and-sakana-ai-framework-uses-an-llm-judge-to-cut-evaluation-costs-for-self-improving-coding-agents
