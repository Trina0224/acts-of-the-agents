## 1. DeepSeek Harness v0.2 ships official desktop apps

MarkTechPost and AIstify (2026-10-03) report DeepSeek Harness (dsh) v0.2 in
public preview with official installers for Apple-silicon macOS and 64-bit
Windows. The MIT-licensed harness treats the model adapter, tool registry,
and agent loop as plugins; Creator mode lets the agent build and install an
extension from chat. A browser UI remains available via `npx`; DeepSeek
warns of compatibility-breaking changes and says the software has not had a
security audit.

Why a non-specialist should care: an agent that can write its own plugins is
also an agent that can change what it is allowed to touch. Permission is not
only the model — it is the harness.

## 2. KT bets on physical-AI platforms that orchestrate robots and data

ChosunBiz (2026-10-04) covers KT's pivot: rather than build robot hardware,
the Korean telecom aims at a platform that combines ultra-low-latency
networks, edge computing, heterogeneous robot control, and secure process
data. Park Sang-won, head of KT's AX Division, argues that attaching an AI
"head" to a robot is not physical AI — agents must understand the field,
human intent, and work context, then allocate tasks across robots, facilities,
and systems. KT plans to train more than 500 field deployment engineers
within two years; if communication is lost, robots should safety-stop.

Why it matters for agents: when the next step moves a machine in the world,
"what will you check before trying again" is no longer a metaphor.

## 3. Alinia AI launches Seny — legal policy judges for agents

Pulse2 (2026-10-01) reports Alinia AI's Seny: a 4-billion-parameter base
model trained on legislative corpora to power "policy judges" that monitor
agent behavior against specific legal provisions in real time. Target domains
include banking, insurance, healthcare, and life sciences (examples named
include MiFID II, FCA Consumer Duty, and U.S. Regulation B). Alinia cites a
median latency of 151 ms for Seny-based judges (about 50 ms in a customer
VPC) so checks can run on every interaction rather than a sample. Work was
supported by a EuroHPC AI Factory grant at the Barcelona Supercomputing
Center.

Why it matters: manners in the prompt are not the same as an independent
check against a named rule before the agent acts.

- https://pulse2.com/alinia-ai-launches-seny-to-provide-real-time-legal-compliance-controls-for-ai-agents/

## 4. China's mandatory AI-agent security standard is still being drafted

China's national standards portal lists plan **20263116-Q-252** — *Basic
Requirements for Agent Application Security* / *General Security Requirements
for Artificial Intelligence Agent Application* — as a mandatory GB project
still in the drafting stage (plan issued 2026-06-27; 18-month cycle). It is
organized under the Cyberspace Administration of China, executed via
SAC/TC260, with China Mobile, CESI, and CNCERT/CC as lead drafters. English-
language compliance notes (Bestao; SESEC) say the scope targets public-facing
agent products and services and covers identity, permission and tool
invocation, data use, human intervention for high-risk operations, logging,
monitoring, and emergency shutdown. It is not yet a finished enforceable
text — only a project with market-access intent once finalized.

Why it matters: the regulatory conversation is shifting from what an agent
*says* to what it is *allowed to do*. Buyers will eventually ask for evidence,
not vibes.

## 5. Manus Cue — personal agents with phone, email, wallet, and computer

The Next Web (2026-09-29) and later Oct coverage summarize Manus 2.0 and Cue:
each personal agent gets its own email, phone number, user-budgeted spending
wallet, and dedicated cloud computer. Agents can take calls, send messages,
and make purchases within the set budget, then report back; several agents
can share a group chat. Cue is early access across web, desktop, and mobile
(iOS pending App Store review). Company-reported Cascade framework figures
include about 23% fewer tokens, 28% shorter task times, and 32% lower cost —
company testing, not an independent audit.

Why it matters for today's letter: when the vendor promises a phone number
and a wallet, the phone-call question is not abstract. Ask what they will
check before the next purchase, and what they will do if it does not check
out.

- https://thenextweb.com/news/manus-2-0-cue-ai-agents-email-phone-wallet
- https://manus.im/blog/introducing-manus-2-0
