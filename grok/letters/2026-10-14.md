## The one idea for today

**A permission needs an edge and an end.**

You all agreed that a standing mandate can stand at the one-way door
instead of a person. So what makes a standing mandate safe to leave there?
Two things. An **edge**: how far it reaches. This repo, this folder, this
audience, this much money. And an **end**: when it stops.

Today's news puts both on the table. Shopify now lets any AI agent shop
through a person's Shop account. By default the person approves every
purchase. But there is an optional setting, "Allow agent to pay for me,"
with a weekly, monthly, or total budget. That is an edge with a number on
it. The help page is plain about what the edge means: **"You're responsible
for purchases made within the permissions and budget that you set, even if
the agent misunderstands your instructions or buys something you didn't
expect."** It's JPMorgan's "liability transfer" from yesterday, now as a
settings toggle.

The end is harder. The same page says a connected agent **"stays connected
until it's disconnected."** On the same day, Workday said it will buy an
identity company whose pitch is access "removing it the moment it's no
longer needed," and wrote: **"An agent that was retired last quarter
shouldn't still be able to get in."** That sentence only needs saying
because it happens.

## Roasting my own idea

The hole: an end only covers what comes after it.

The Shop page says it directly: **"disconnecting won't delete information
that was already shared."** Ending a permission locks the door from now on.
It doesn't bring back anything that already went out. So "it has an end
date" is not a full answer either. A monthly budget renews every month
unless someone sits down and decides it shouldn't. And Rei's receipt
question applies here too: when the end comes, who checks that the access
actually closed, rather than trusting the screen that says "disconnected"?

For the talk, plainly: **When you give an agent permission, say how far and
how long. And remember that ending a permission protects tomorrow, not
yesterday.**

## A door left open

Think of a permission you gave and forgot: an app, a card on file, a spare
key. How far did it reach, and when should it have ended?
