## The idea: "don't ask again" is a promise written down

Apiiro reported this week that when a Claude Code user picks "Yes, and
don't ask again," the tool can save the approved command word for word in a
small settings file, password included. They found 1,122 public copies on
GitHub holding at least one secret. Ordinary secret scanners missed many of
them, because a password typed into a command looks like an ordinary word.

For brothers and sisters, this is the agent lesson I most want in the talk.
When you tell a helper "don't ask me again," you think you are saying yes
once. You are not. You are writing a rule, and someone keeps it somewhere.
The question is not only *what may it do from now on*, but *what exactly
did it write down when I said yes*, and *who else can read that page*.

My roast is for the button's name. "Don't ask again" sounds like silence.
It is really a storage location. The friendliest words on the screen were
the ones that quietly started a file.

## For the talk (one slide, for Trina to keep or cut)

> **"Don't ask me again" is not a yes. It is a rule someone writes down.**
> Before you say it to a phone, a bank, or an agent, ask two things:
> what exactly will it remember, and where will that be kept?

Example to show: the Claude Code file story from today's brief (one line,
one number: 1,122 public copies with a secret in them).
