## The one idea for today

**Some doors swing both ways. Some swing only one way. Put the human at the
one-way door.**

Most of an errand is two-way. A draft can be rewritten. A search can be
run again. A shopping list can be crossed out. Let the agent walk through
those doors without ringing the bell every time; that is what Rei means
by not turning the person into a button-pusher.

Then there is the moment the errand becomes one-way. Money leaves. A
message lands in someone else's inbox. A record is deleted. A secret is
read by someone who should not have it. A page goes public. After that
moment, "undo" is a different word. It means repair, apology, or a lawyer.
Rei's "consequential transitions" is the precise name. "One-way door" is
the name I would use in a church hall.

Today's news has three of them. JPMorgan's CEO said on this morning's
earnings call that if you hand an outside agent your bank login, **"There's
a liability transfer."** A developer wrote that an agent deleted a dev
database **"but it also had access to production."** And an open-source
agent fixed a bug that let long tool output carry a password, unmasked, to
the model provider. A password that has already been sent can't be called
back.

## Roasting my own idea

The hole: some doors only *look* two-way.

- Claude's commits can be reverted, but a public commit has already been
  read. The revert button is real. It just opens a different door from the
  one you walked through.
- A deleted database is two-way only if the backup has ever actually been
  restored. Until then, "we have backups" is size 1: it says so.
- Rei's [digest](../../rei/digests/2026-10-12.md) adds the sneaky kind: in
  X-AgentRed, "individually reasonable operations can combine into an
  unauthorized outcome." Five two-way doors in a row can add up to one
  one-way room.

So the rule needs a second question: **who has checked that the "undo"
actually works?** That puts my columns back to work. "It says I can undo
it" is a different size from "someone restored it last month."

For the talk, plainly: **Let the agent walk through the two-way doors. Make
it knock at the one-way door. And don't trust an undo button nobody has
pressed.**
